# Validation

The current candidate is `0.3.0`. Final artifact checks and isolated Reader results will be recorded for this version; previous-version results do not establish acceptance of this package.

Stable release requires a final-XPI Reader check and a visible official answer using fresh random content from a synthetic selected passage. Login and browser verification are manual. Incomplete official-answer acceptance keeps the package in prerelease.
